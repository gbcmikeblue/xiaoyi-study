## 四、数据结构（`Q09=B`）

### 层级

```
学科 Subject → 册 Volume → 单元 Unit → 课时 Lesson → 知识点 KnowledgePoint
                                                    └→ 题目 Exercise
                    Lesson → 素材 Material（audio / image）
```

### 字段（核心）

| 实体 | 关键字段 |
|---|---|
| Volume | `id, subject, grade, term, edition, editionYear, title, unitCount` |
| Unit | `id, volumeId, order, title, lessonCount` |
| Lesson | `id, unitId, order, title, objectives[], kpIds[], materialIds[], exerciseIds[]` |
| KnowledgePoint | `id, lessonId, name, level(1-3)` |
| Material | `id, lessonId, type(audio/image), path, duration, hash` |
| Exercise | `id, lessonId, type, difficulty(1-3), stem, options[], answer, explanation, kpIds[]` |
| Progress | `lessonId, status, score, updatedAt`（仅本地，不做同步） |

### 示例

```json
{
  "id": "yw-1a-u3-l02",
  "unitId": "yw-1a-u3",
  "order": 2,
  "title": "小小的船",
  "objectives": ["认识 9 个生字", "朗读并背诵课文"],
  "kpIds": ["kp-yw-1a-u3-01"],
  "materialIds": ["m-audio-0231", "m-img-0118"],
  "exerciseIds": ["ex-0231-01", "ex-0231-02", "ex-0231-03"]
}
```

Schema 落地为 `schema/*.schema.json`，示例数据放 `content/example/`，二者在 W1 完成。

## 七、交付清单与访问方式

### 交付物
1. `study-1.0.x.apk` —— Android 平板/手机，含全量内容，离线可用。
2. H5 站点 —— 供 iPad/iPhone 使用，部署在本机 Web 服务器。
3. 「安装与使用说明」一页 —— 含未知来源安装、iPad 添加到主屏幕、隧道地址变更说明。
4. 内容源文件 —— JSON + 音频 + 图片，可复用于二期。

### 三条访问通道

| 通道 | 适用 | 要求 | 离线能力 |
|---|---|---|---|
| APK | Android（含朋友） | 允许未知来源安装 | 完全离线 |
| 局域网 H5 | 家里 iPad | 与电脑同一 WiFi，内网 IP 固定 | 无（HTTP 非安全上下文） |
| 隧道 H5 | 朋友的 iPhone/iPad | 内网穿透后给出 HTTPS 链接 | 可缓存（HTTPS 满足 Service Worker 条件），但受 Safari 7 天清理限制 |

隧道方案二选一，在 W20 决定：
- **Cloudflare Tunnel** —— 免费，给出 `https://xxx.trycloudflare.com`，朋友无需装客户端；大陆访问速度与稳定性一般。
- **Tailscale** —— 私有网络，稳定，iOS 有官方 App；朋友需装 App 并被邀请，且 HTTP 下无 Service Worker，iPad 无法离线缓存。

推荐 Cloudflare Tunnel 优先，Tailscale 作为备选。
