# 面向深圳小学一年级各学科课程的 H5 教学项目选型评估报告

> 调研时间：2026-10-31 ｜ 调研范围：GitHub 公开仓库 ｜ 结论口径：以「深圳一年级实际教材版本 + 安卓/iOS/iPad/平板多端」为基准

---

## 一、先明确「深圳一年级」的内容基准（选型的判据）

深圳义务教育免费课本由政府统一选用，一年级各科版本与全国多数地区**并不一致**，这是筛选项目时最关键的一刀：

| 学科 | 深圳一年级教材版本 | 与全国主流（人教版）差异 |
|---|---|---|
| 语文 | 人教社（统编版/部编版） | 一致 |
| 道德与法治 | 人教社（统编版） | 一致 |
| 数学 | **北京师范大学出版社（北师大版）** | **不一致** |
| 英语 | **上海教育出版社（沪教版/沪教牛津）**，一年级即开设 | **版本不一致，且内地多数地区三年级才开英语** |
| 科学 | 教育科学出版社（教科版） | 一致 |
| 音乐 | 广东花城《走进音乐世界》 | 地方版本 |
| 美术 | 岭南美术出版社 | 地方版本 |
| 地方教材/专题 | 海天出版社、深圳报业（写字、心理健康、劳动实践、综合实践、法治读本等） | 深圳区本 |

依据：深圳市《义务教育阶段免费课本政府选用目录》（sz.gov.cn 公开附件）、深圳市教材版本公开目录。

> **结论先行：调研范围内不存在任何针对「深圳版教材 + 一年级全学科 + 多端 App」的现成开源项目。** 最接近的方案在「内容规模」或「跨端架构」单点上很强，但都无法直接交付。下文按单点能力分别排序。

## 三、逐个评估

### 1. 聪聪学堂（ChinaTextbookStudyFree）— 内容与三端骨架最强，但「版本不对」

**功能覆盖**：语文（统编 1–6 年级）、数学（人教 1–6 + 青岛五四制）、科学（教科 1–6）、英语（人教 PEP 3–6）。v1.8.0 计 84 册教材版本、4,448 个常规课时、629 单元挑战、约 3.4 万道题、1,311 篇课文听读、284 篇 AI 课外故事、11.9 万个 MP3。功能含单元小测、知识讲解、课本原页逐句听读 + 跟读录音、SRS 错题本、周报、家长时长限制。

**跨端与设备**：
- iOS/iPadOS：**SwiftUI 原生**（XcodeGen），iPad 自动分栏，AVAudioPlayer + AAC，教材数据按书从 Release 按需下载 —— 是三端里最完整的，但**未签名、未上架、真机验收未完成**。
- Android：`apps/android` 是 **WebView 在线壳**，GitHub Actions 出 debug APK，非原生实现。
- PWA：**未完成**（README 路线图明确列为待补）。

**技术基础**：Next.js + TypeScript + Zustand + Tailwind，静态导出；`packages/core` 为跨端共享域逻辑（SRS/判分/成就）；Python 数据管线 `scripts/quiz`（PDF→大纲→题库）、`scripts/tts`（Edge TTS）；Docker 部署建议 ≥100 GB 磁盘。

**许可**：MIT（**仅代码**，不授予教材文本/图片权利）。**风险**：正式版部署体积巨大；题目为 AI 生成且**教师逐题审核尚未完成**；教材年份为 2010–2022 版次，非最新。

**对深圳的差距**：①数学是人教版，深圳是北师大版；②英语从三年级起，深圳一年级即开英语且用沪教版；③缺道德与法治（路线图待补）、音乐、美术、地方课程。→ **不能直接用，但数据管线 + 跨端分层架构值得直接复用。**

### 2. hanzi-study — 单点最实用的「即插即用」基底

纯静态、完全离线（音频图片本地）、无构建工具，Docker/Nginx 一行起；声明支持平板/手机/电脑，触屏点读、画一画、护眼模式。功能：1200+ 汉字（拼音/笔画/听音识字/闯关/单元测验）、10 或 100 以内加减法、1–6 年级古诗（朗读 + 拼音 + 注释）。MIT，240 star，是本次候选里**工程门槛最低、许可最干净、最容易被 Capacitor/Cordova 包成三端 App** 的一个。

**差距**：内容按「通用字表/启蒙」组织，不按教材单元编排；单文件页面级架构，无课程 Schema，扩展到「深圳版全学科」需重构数据层。

### 3. Strokes — 跨端架构最贴合需求，但许可卡死商用

uni-app 3 + Vue3 + TS + Vite **一套代码出 H5 / 微信小程序 / Android / iOS**，正是用户要的多端形态。自研笔画引擎 + 0–100 分多维评分（笔画数/笔顺/位置方向/长度比例）、9575 字 SVG 数据全内置、离线 <50 ms、Tesseract.js 离线 OCR、教师端可一键生成交互课件。**许可为 PolyForm Noncommercial 1.0.0 —— 禁止商业使用**，另有 `LICENSE.zh-Hans.md` 中文版。

**对深圳的差距**：场景是新疆双语（维/哈）书写教学，非一年级全学科；许可决定它只能作**架构参照**（uni-app 多端分层的写法可借鉴，代码不可直接商用）。

### 4. mini-classroom — 最贴「一年级上下册」的轻量内容站

数学一年级下册（人教）23 个知识点、语文一年级下册（人教）6 大模块（古诗/背诵/日积月累/词语/近反义词/句式仿写）、英语通用 850 词体系。纯静态零依赖，`localStorage` 存进度，数学与英语站支持 PWA 离线，响应式适配手机平板。MIT，28 star。

**差距**：仅一年级下册；数学是人教版；语文站不做 PWA；无 App 壳；数据层是 `wordData.js`/`data.js` 手写文件，规模化需换 Schema。

### 5. courseware-engine — 课堂大屏（非平板）路线的代表

一套内核产两类成品：**单文件 HTML 交互课件**（资源全 base64 内嵌、纯 ES5、可离线放映）与 **A4 PDF 试卷 + 答案卷**。含 14 个组件包、33 个特效预设、535 种 SVG、5 种试卷版式 33 种题型；带注音校对（pypinyin 逐字比对）、版位/触摸/遮挡体检（1366×768、1920×1080、1024×768 三档**仅用触摸**完成全流程）、Playwright 出 PDF。

**设备结论**：**支持触摸，但舞台固定 1600×900 等比缩放、不重排布局**，定位是教室一体机横屏大屏，**不是手机/竖屏平板产品**。构建依赖 macOS + Homebrew + Playwright + 多个 CLI，开箱复现困难；课本页图因版权未随仓库发布，部分示例必然构建失败；0 star。

**适配深圳**：可作「课堂投屏 + 纸质练习」路线的一年级数学底座，但需重做北师大版内容，且需补一套 1024×768 / 16:10 平板横屏的舞台策略。

### 6–8. 不建议直接采用

- **kid-learn**：uni-app 五科 144 关卡，H5/PWA + 云打包 APK/IPA 路径写得很清楚，但**仓库无 LICENSE**（默认保留所有权利），且内容为幼小衔接通用，不对齐教材、只到一年级。
- **VBCoding**：321 个一年级生字 + iPad 手写笔支持，但**无开源许可**（README 写「仅供个人学习和教育使用」），2 次提交，笔顺功能在 v1.4 被移除。
- **math-teaching-for-primary-grades**：Apache-2.0 看着漂亮，但仓库实际**只有 LICENSE 文件**，无可运行代码，不可评估。

## 四、跨平台与设备适配横向结论

| 交付形态 | 可用的现成方案 | 关键约束 |
|---|---|---|
| **Android App** | 聪聪学堂（WebView 壳 + CI debug APK）、kid-learn / Strokes（uni-app / HBuilderX 云打包） | 均未正式发布；国内分发需软著 + 各应用商店资质 |
| **iOS / iPhone** | 聪聪学堂 SwiftUI（未签名）、uni-app 系（需 $99 开发者账号） | HBuilderX「标准基座」2022 年起无法直装 iOS 真机，须自有证书重签 |
| **iPad / 平板** | 聪聪学堂 iPad 分栏（最完整）、uni-app 系 H5 全屏、hanzi-study/mini-classroom 响应式 | 教室大屏类项目（courseware-engine）固定 1600×900，不适配竖屏平板 |
| **离线 / PWA** | hanzi-study（完全离线）、mini-classroom（部分站）、kid-learn（全站 PWA） | 聪聪学堂 PWA 未完成；PWA 需 HTTPS + 国内域名 ICP 备案 |
| **微信小程序** | Strokes 有 `build:mp-weixin` | 一年级家长触达率高，值得作为第四端 |

**共性缺口**：全部候选都没有「教师端班级管理 + 学生账号 + 跨设备进度同步」。聪聪学堂明确无云端账号、仅支持手动导入导出；kid-learn 进度只在本地存储，清站点数据即丢。若要做班级化教学，这一层必须自建。

## 五、开源许可与合规风险清单

| 风险 | 涉及项目 | 处理建议 |
|---|---|---|
| MIT 只覆盖代码，不覆盖教材 | 聪聪学堂、courseware-engine、mini-classroom、hanzi-study | 教材原页/插图不可随包分发，改用自绘示意或取得授权 |
| 非商业许可禁止商用 | **Strokes（PolyForm NC）** | 仅借鉴架构；商用需替换代码或取得作者授权 |
| 无 LICENSE = 保留所有权利 | **kid-learn、VBCoding** | 不可再分发/商用，仅可内部参考 |
| 素材版权缺失 | courseware-engine（人教课本页、试卷图标、macOS `say` 语音） | 需自备素材重渲染 |
| 儿童合规 | 全部面向 6–7 岁 | 《儿童个人信息网络保护规定》、未成年人模式、不得默认采集；离线优先最稳 |
| 分发合规 | 面向深圳学校/家长 | 软著、ICP 备案、教材选用与校本审核流程 |

## 六、推荐优先级与选型建议

### 优先级

| 优先级 | 对象 | 定位 | 理由 |
|---|---|---|---|
| **P0** | 聪聪学堂（ChinaTextbookStudyFree） | **架构与内容管线参照 + Web 底座候选** | 唯一同时具备「全学科全册内容 + 数据管线 + Next.js Web + SwiftUI iPad 原生 + Android 壳」的项目，MIT 可商用改 |
| **P0** | hanzi-study | **MVP 首选交付基底** | MIT、纯静态、完全离线、平板/手机已可用，一周内可包出 Android/iPad 可试用版 |
| **P1** | mini-classroom | 一年级下册语数内容补充 | MIT，内容粒度（人教版单元/知识点）最接近一年级实际教学进度 |
| **P1** | Strokes（仅架构） | **多端工程模板** | uni-app 一套代码四端 + 本地大容量字库 + 离线评分的写法可直接照搬 |
| **P2** | courseware-engine | 课堂大屏 / 纸质练习双轨分支 | 单文件 HTML 离线放映 + PDF 试卷流水线，适合「教室一体机 + 打印」场景 |
| **不采用** | kid-learn、VBCoding、math-teaching-for-primary-grades | — | 许可缺失 / 空仓库 |
| **配套** | tchMaterial-parser + ChinaTextbook | 深圳版教材电子化的素材获取与比对 | MIT 工具；仅用于内部比对与结构提取，不随产品分发原页 |

### 两条落地路径

**路径 A（4–6 周出可用版，推荐先走）**
1. 以 hanzi-study 或 mini-classroom 的静态站为壳，抽出统一的课程数据 Schema（`学科/年级/册/单元/课时/知识点/题型`）。
2. 按深圳版本重写内容：**数学换成北师大版一年级上/下册目录**（这是与所有候选的最大差异点），**英语补一年级沪教版**（深圳一年级开英语，候选项目全部缺这一段）。
3. 用 **Capacitor** 封装 Android / iOS / iPad 三端（比 uni-app 云打包更可控，无需 HBuilderX 证书流程），保留 H5/PWA 作为第四交付形态。
4. 竖屏手机 + 横屏平板双布局；课堂投屏场景单独一套 16:9 舞台。

**路径 B（3–4 个月做完整平台）**
1. Fork 聪聪学堂，复用其 `scripts/quiz`（PDF→大纲→题库）与 `scripts/tts` 管线，把深圳版 7 科教材灌进去（数学北师大、英语沪教、科学教科、音乐花城、美术岭南、道法统编、地方教材）。
2. 前端统一到 uni-app 3（借 Strokes 的分层写法）或保留 Next.js + 静态导出，用 Capacitor/原生壳出三端。
3. 补齐候选项目集体缺失的三件事：**PWA 全库离线预缓存、账号与跨设备进度同步、教师端班级/作业/学情面板**。
4. 教材内容一律走「知识点重绘 + 自研题目」，不复刻课本原页，规避版权。

### 一句话结论

> 没有任何 GitHub 项目能直接满足「深圳一年级全学科 + 安卓/iOS/iPad 全端」；**内容层用聪聪学堂的管线、交付层用 hanzi-study + Capacitor 快速起步、多端架构参照 Strokes**，是当前风险最低、见效最快的组合。真正的差距不在代码，而在**北师大版数学 + 一年级沪教版英语 + 深圳地方课程**这三块内容无人做过。
